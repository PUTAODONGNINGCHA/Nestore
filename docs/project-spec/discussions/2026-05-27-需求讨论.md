# 需求讨论记录

> 日期：2026-05-27
> 参与者：用户 + Claude

---

## 项目定位

打造一个**真正属于自己的个人云盘**，供家庭成员共享使用。

- 不是临时的文件分享工具，而是长期的文件存储和管理平台
- 全家共享一个空间，所有文件对所有人可见
- 只需一个共享密码即可访问，无需多用户注册

## 用户群体

- **个人 + 家人**（约 2-3 人）
- 小范围使用，不对外开放

## 技术栈

- **前端**：React + TypeScript + Vite
- **样式**：Tailwind CSS（简洁现代风格，用户授权自由设计）
- **后端/数据库**：Supabase（免费版）
  - Supabase Auth（单用户共享账号）
  - Supabase PostgreSQL（文件元数据、文件夹树）
  - Supabase Storage（文件存储）
- **部署**：待定（Vercel / Netlify 等免费平台）

## 核心功能需求

| 功能 | 说明 |
|------|------|
| 密码登录 | 设置一个共享密码，家人输入密码即可访问 |
| 文件浏览 | 文件夹导航、面包屑路径、文件列表展示 |
| 文件上传 | 支持拖拽上传和点击选择上传 |
| 文件下载 | 点击文件即可下载 |
| 文件夹管理 | 新建、重命名、移动、删除文件夹 |
| 文件管理 | 重命名、删除文件 |
| 文件预览 | 在线预览图片、视频、PDF、文档等 |

## 非功能性需求

| 需求 | 说明 |
|------|------|
| 安全性 | 单密码访问保护，文件存储访问受控 |
| 可扩展性 | 后续可方便更换存储后端（Supabase → S3/MinIO 等） |
| 免费可用 | 在 Supabase 免费版额度内运行（1GB 存储、2GB 带宽） |
| 移动端适配 | 响应式设计，手机也能浏览和上传 |

## 重要决策

1. **无需分享链接**：家人直接登录使用，不设分享功能
2. **单密码共享**：不采用多用户注册体系，降低使用门槛
3. **后续可扩容**：通过适配器模式设计存储层，方便未来迁移
